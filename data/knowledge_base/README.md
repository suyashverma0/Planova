# Planova Knowledge Base & Skill Graphs

This directory stores structured skill graphs and dependency seed files in YAML/JSON formats.

Seed targets:
1. `ml_engineer.yaml` — Machine Learning Engineer roadmap & dependencies
2. `data_scientist.yaml` — Data Scientist skill tree
3. `web_developer.yaml` — Full Stack Web Development tree
4. `nimcet_prep.yaml` — NIMCET entrance exam topic hierarchy & hour estimates

In Phase 3, these files will be validated (ensuring prerequisite edges form a Directed Acyclic Graph) and seeded into the database `skills` and `skill_edges` tables.
